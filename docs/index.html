Structure Relaxor is not available in the browser

        
The Structure Relaxor runs vasp-mace with the MACE-MH-1 machine-learning potential. This needs PyTorch and several GB of
        software, which cannot run inside a web page. Activity Screening and the DOS Predictor on this site run entirely in your browser, so your files never leave your computer.

        
To relax structures, use one of these:

        
    
          
  • Desktop app (Windows, macOS, Linux): the full Padarth Khoj with all three tools, installed with one click.
            github.com/ranjitphy/padarthkhoj
    • 
          
  • Self-hosted web version: the same interface served from your own computer or server with Docker or run.sh / run.bat.
    • 
        

        
Cite vasp-mace (Grau-Crespo, R., Zenodo, doi:10.5281/zenodo.19479246) and MACE (Batatia et al., NeurIPS 2022) if you use relaxed structures in your work.
